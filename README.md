# CodeMentor AI

CodeMentor AI is a domain-specialized chatbot designed to help
students learn Computer Science and programming.

## Features
- Computer Science educational assistance
- Python, Java, C++, and JavaScript support
- Artificial Intelligence and Machine Learning explanations
- SQL and database assistance
- Domain-specific response restrictions
- Conversation history
- Error handling
- Streamlit user interface

## Technology Stack
- Python
- Google Gemini 3.5 Flash
- Google GenAI SDK
- Streamlit

## Model Configuration
- Temperature: 0.4
- Maximum output tokens: 700

## Run Locally
Install dependencies:

pip install -r requirements.txt

Set GEMINI_API_KEY in Streamlit secrets.

Run:

streamlit run app.py
